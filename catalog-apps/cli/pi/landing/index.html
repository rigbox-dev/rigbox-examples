Pi.

Pi is a CLI coding agent — there's no web UI to point a browser at. SSH into this workspace and run pi.

Use it

rig workspace ssh
$ pi
> refactor the auth handler to use early returns

Where the AI credits come from

Pi reads OPENROUTER_API_KEY directly. This example opts into the Rigbox managed AI proxy, so the workspace env layer injects a placeholder key and routes calls through workspace credits — no real OpenRouter key required.

Bring your own key instead with rig app secret set OPENROUTER_API_KEY=<your-key>.
