Claude Code

Anthropic's AI coding agent is installed in this workspace. It's a terminal app — open an SSH session to use it.

1. Get the SSH command

rig workspace ssh-info --workspace <name-or-id>

2. Connect and run

ssh "$(rig workspace ssh-info --workspace <name-or-id> --output json | jq -r .ssh_target)"
claude

Routing

Requests go through OpenRouter using the OPENROUTER_API_KEY forwarded at deploy time — /etc/profile.d/claude-routing.sh translates it to the ANTHROPIC_* env Claude Code reads.
